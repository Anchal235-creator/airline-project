 ✈️ Airline Booking System

A full-stack Airline Booking System built using HTML, CSS, JavaScript, Node.js, and MySQL. The system allows users to search flights, book tickets, and manage reservations, along with an admin dashboard for flight and booking management.

 🚀 Features
- User Registration & Login
- Flight Search
- Ticket Booking
- Booking Management
- Admin Dashboard

 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Database: MySQL
